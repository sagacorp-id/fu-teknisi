# Dashboard FU Teknisi

Dashboard FU Teknisi · Internasional Komputer Karanganyar · Be The Best Service

Halaman web mandiri (PWA) untuk membuat pesan FU WhatsApp, kalkulator biaya, dan riwayat FU.
Data dan login PIN diproses oleh server Google Apps Script (link /exec di `config.js`).
Tidak ada data customer, PIN, atau API key yang disimpan di repository ini.

## Pasang di HP
- **Android (Chrome):** buka link → menu ⋮ → *Instal aplikasi* / *Tambahkan ke layar utama*.
- **iPhone/iPad (Safari):** buka link → tombol *Bagikan* → *Tambah ke Layar Utama*.
